# GitHub Pages Deploy

- This repo publishes to GitHub Pages through `.github/workflows/deploy-pages.yml`.
- The Pages build is a static catalog export for `https://dacameragirl.github.io/andys-woodworks/`.
- Server-only checkout and webhook routes are not part of the Pages build, so the public Pages site uses direct inquiry/contact flow instead.
- If Pages is still configured as `Deploy from a branch`, switch it to `GitHub Actions` in `Settings -> Pages`.
